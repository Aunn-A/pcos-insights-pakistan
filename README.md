# PCOS Insights Pakistan

> Understanding the reality behind the diagnosis.

A student-led public health research initiative exploring how Polycystic Ovary Syndrome (PCOS) affects adolescent girls and young women across Pakistan — through a national survey, an open insights dashboard, and firsthand accounts.

## Pages

- **Home** — mission overview, headline stats, dashboard and voices previews
- **About** — the initiative's origin, research phases, and ethics commitments
- **Learn About PCOS** — symptoms, myths vs. facts, and FAQ
- **National Survey** — anonymous survey entry point (Google Form link to be added)
- **Insights Dashboard** — diagnosis journey, healthcare access gap, education impact index, and mental health snapshot charts
- **Voices Behind the Data** — anonymized respondent reflections
- **Get Involved** — ways to participate, partner, or volunteer

All statistics and quotes are illustrative placeholders pending real national survey data.

## Stack

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui · Framer Motion · Recharts · Lucide Icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Before going live

- Replace the placeholder `SURVEY_FORM_URL` in `src/app/survey/page.tsx` with the real Google Form link.
- Swap illustrative dashboard/quote data for verified survey results.
